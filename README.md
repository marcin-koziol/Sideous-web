# Sideous Web

Landing page for the [Sideous](https://github.com/marcin-koziol/Sideous-synth)
plugin family — [Sideous](https://github.com/marcin-koziol/Sideous-synth),
[Sideous Drums](https://github.com/marcin-koziol/Sideous-drums),
[Sideous Noise](https://github.com/marcin-koziol/Sideous-noise),
[Sideous Pad](https://github.com/marcin-koziol/Sideous-pad), and
[Sideous Bass](https://github.com/marcin-koziol/Sideous-bass).

Static single-page site (`index.html`), served via GitHub Pages from the
repo root on the `main` branch.
